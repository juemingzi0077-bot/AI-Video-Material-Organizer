# Game Material Organizer V0.1

Game Material Organizer 是 AI 游戏/视频生产流水线中的第一个素材管理模块。

## 项目目标

自动扫描游戏或 AI 视频素材文件夹，提取视频的文件名、完整路径和最后修改时间，并生成 `materials.csv`。

## 当前 V0.1 功能

- 用户输入素材文件夹路径
- 检查路径是否有效
- 支持 `.mp4`、`.mov`、`.mkv`、`.avi`、`.webm`
- 只扫描当前目录，不扫描子文件夹
- 获取文件名、完整路径和最后修改时间
- 按修改时间从旧到新排序
- 生成 `materials.csv`
- 不移动、不删除、不重命名任何原始视频

## 运行方法

在项目目录执行：

```bash
python main.py
```

然后输入需要扫描的素材文件夹路径。

## 当前限制

- 只扫描当前目录
- 不读取视频时长
- 不读取分辨率和帧率
- 不分析视频内容
- 不识别人物、剧情和场景
- 不调用 AI API
- 不修改任何原始文件
