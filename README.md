# AI Video Material Organizer

AI视频素材管理器

AI Video Material Organizer 是 AI 视频生产流水线中的第一个素材资产管理模块。

它负责扫描、整理和结构化记录视频素材信息，为后续 AI 视频分析、搜索、剪辑和自动化生产流程提供基础数据。
## 项目目标

自动扫描 AI 视频素材文件夹，提取视频元数据，建立结构化素材索引，并生成 `materials.csv`。

## 当前 V0.2 功能

- 用户输入素材文件夹路径
- 检查路径是否有效
- 支持 `.mp4`、`.mov`、`.mkv`、`.avi`、`.webm`
- 只扫描当前目录，不扫描子文件夹
- 按修改时间从旧到新排序
- 生成 `materials.csv`
- 不移动、不删除、不重命名任何原始视频
- 获取文件名、完整路径和最后修改时间
- 获取视频文件大小

## 运行方法

在项目目录执行：

```bash
python main.py
```

然后输入需要扫描的素材文件夹路径。

## 当前限制

- 只扫描当前目录
- 不读取视频时长
- 不读取分辨率和帧率
- 不分析视频内容
- 不识别人物、剧情和场景
- 不调用 AI API
- 不修改任何原始文件
